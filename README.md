# Portfolio_website

My first-ever portfolio website — built by **Arpan Adhikari**, Computer Engineering student, using plain **HTML, CSS, and JavaScript**.

This was where it all started. No frameworks, no build tools — just raw front-end fundamentals and a lot of trial and error. It's got its rough edges, but it taught me the basics that everything else was built on. Kept it around as a personal milestone rather than a polished product.

## 🛠️ Built With
- HTML5
- CSS3
- JavaScript (vanilla)

## ✨ Features
- Smooth scroll navigation
- Responsive layout
- Custom UI styling
- CV download section
